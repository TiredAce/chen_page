# 个人网站

一个基于 Vue3 的现代化个人网站，采用深色主题设计，单页滚动布局。

## 功能特点

- 🎨 深色主题，渐变色彩设计
- 📱 响应式布局，适配各种设备
- 🚀 单页滚动，流畅的导航体验
- ✨ 现代化UI设计，动画效果
- 📋 包含首页、关于我、知识空间、技能与生活、联系方式等模块

## 技术栈

- Vue 3 (Composition API)
- Vite
- CSS3 (渐变、动画)

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

项目将在 `http://localhost:3000` 启动

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 项目结构

```
person_website/
├── index.html          # HTML入口文件
├── package.json        # 项目配置
├── vite.config.js     # Vite配置
├── src/
│   ├── main.js        # 应用入口
│   ├── App.vue        # 主组件
│   └── style.css      # 全局样式
└── README.md          # 项目说明
```

## 自定义内容

你可以在 `src/App.vue` 中修改以下内容：

- 个人信息（姓名、简介、学校等）
- 知识空间卡片内容
- 联系方式信息
- 技能列表
- 关于我的描述
